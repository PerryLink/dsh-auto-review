# Privacy

`dsh-auto-review` is a local DeepSeek Harness plugin.

- It reads only the workspace files, configuration and tool inputs needed for its documented features.
- It does not add telemetry, analytics, advertising or a hosted account, and it sends no data to PerryLink.
- Any network access or external service used by the plugin is documented in its README and is controlled by the user's own configuration.
- It writes no data outside the DSH profile, the workspace, and the host's own session/log storage. The host controls that storage and its retention.
- Removing the package removes its code; it does not delete host logs, workspace files or documents you already created.

This statement covers the npm package, not the DSH host or any other plugin in the profile.
